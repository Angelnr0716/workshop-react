2.2 ¿Cómo se relacionan?
React y Vue se crean, en este curso, con Vite: Vite les da el servidor de desarrollo y la compilación. (Antes, React usaba «Create React App», retirada en 2025.)
Angular trae su propia herramienta (Angular CLI). Por dentro también usa esbuild y Vite para el servidor de desarrollo.
Tailwind sirve con cualquiera de los anteriores: es solo CSS. En este curso se instala sobre Vite.
Bootstrap, que usted ya conoce, también puede usarse dentro de React, Vue o Angular.
NOTA · El hilo conductor: Node.js y npm
Las cinco tecnologías se instalan con npm, el gestor de paquetes de Node.js. Node.js permite ejecutar JavaScript fuera del navegador; aquí lo usamos para correr las herramientas de desarrollo (no para hacer un backend). Por eso el primer paso es instalar Node.js (sección 4).

4. Fase 0 · Preparación del entorno
React necesita Node.js y npm. Usaremos la versión 24 LTS (soporte de largo plazo), que cumple los requisitos de las cinco tecnologías del curso. La instalaremos con nvm (Node Version Manager), que permite tener varias versiones de Node y evita problemas de permisos. Todos los aprendices del curso hacen esta fase, porque en los workshops todos van a programar.
IMPORTANTE · ¿Por qué no `sudo apt install nodejs`?
La versión de Node que trae Ubuntu en sus repositorios suele ser antigua (Angular 22, por ejemplo, exige Node 22.22 o superior). Además, con apt hay que usar sudo para instalar paquetes globales, lo que causa errores de permisos. Con nvm todo queda en su carpeta personal.
 1   Abra una terminal en su máquina virtual Ubuntu e instale curl, git y nvm:
Terminal   Terminal
sudo apt update && sudo apt install -y curl git
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash
 2   Cierre la terminal y abra una nueva (o ejecute source ~/.bashrc) para que reconozca nvm. Verifique:
Terminal   Terminal
nvm --version
 3   Instale Node.js 24 LTS y déjelo como versión predeterminada:
Terminal   Terminal
nvm install 24
nvm alias default 24
node -v     # debe mostrar v24.x.x
npm -v      # debe mostrar 10.x o superior
 4   Configure Git con su nombre y correo:
Terminal   Terminal
git config --global user.name "Su Nombre"
git config --global user.email "su_correo@ejemplo.com"
 5   Cree la carpeta donde guardará sus proyectos:
Terminal   Terminal
mkdir -p ~/proyectos

4.1 Problemas frecuentes de instalación
Síntoma
Causa
Solución
nvm: command not found
La terminal no recargó la configuración.
Cierre y abra la terminal o ejecute source ~/.bashrc.
EACCES: permission denied al instalar con -g
Node instalado con apt y no con nvm.
Desinstale el de apt (sudo apt remove nodejs) y use nvm.
npm install tarda mucho o falla con ETIMEDOUT
Red lenta o bloqueada.
Reintente; verifique la conexión o pruebe en otra red. Un npm install normal toma de 20 s a 2 min.
«Port 5173 is already in use»
Hay otro servidor de desarrollo abierto.
Cierre la otra terminal (Ctrl + C) o use el puerto que Vite le ofrece.

7.2 ¿Qué es y para qué sirve?
React divide la interfaz en componentes: funciones de JavaScript que devuelven lo que se debe ver. Cuando los datos (estado) cambian, React vuelve a dibujar solo lo necesario. Usted describe cómo debe verse la pantalla según los datos, y React se encarga de actualizar el DOM.
React es «solo» la capa de la vista: para rutas, peticiones al servidor o formularios complejos se combina con otras librerías, o se usa un framework construido sobre React como Next.js o React Router. Con React Native se crean apps móviles con la misma forma de pensar.
7.3 Conceptos clave
Concepto
Qué significa
Componente
Función que devuelve JSX. Su nombre empieza con mayúscula: TarjetaProducto.
JSX
Sintaxis parecida a HTML dentro de JavaScript. Usa className en lugar de class y { } para insertar valores.
Props
Datos que un componente padre le pasa a un hijo: <TarjetaProducto producto={p} />.
Estado (useState)
Datos que cambian con el tiempo. Al cambiarlos con su función set…, el componente se vuelve a dibujar.
Eventos
onClick={() => …} ejecuta una función al hacer clic.
Listas y key
array.map() convierte datos en elementos; cada uno necesita una key única.
Hooks
Funciones especiales que empiezan por use: useState, useEffect…

src/App.jsx  (archivo completo)   JavaScript
import { useState } from 'react'
import { productos, formatoPesos } from './datos.js'
import TarjetaProducto from './components/TarjetaProducto.jsx'
 
const categorias = ['todas', 'hombre', 'mujer', 'accesorios']
 
function App() {
  // Estado: cuando cambia, React vuelve a dibujar el componente
  const [filtro, setFiltro] = useState('todas')
  const [carrito, setCarrito] = useState([])
 
  const visibles =
    filtro === 'todas' ? productos : productos.filter((p) => p.categoria === filtro)
  const total = carrito.reduce((suma, p) => suma + p.precio, 0)
 
  function agregar(producto) {
    setCarrito([...carrito, producto])
  }
 
  return (
    <>
      <header className="encabezado">
        <h1>Brisa Moda · React</h1>
        <span className="carrito">
          Carrito: {carrito.length} · {formatoPesos.format(total)}
        </span>
      </header>
      <main>
        <div className="filtros">
          {categorias.map((c) => (
            <button key={c} className={c === filtro ? 'activo' : ''} onClick={() => setFiltro(c)}>
              {c}
            </button>
          ))}
        </div>
        <div className="grilla">
          {visibles.map((p) => (
            <TarjetaProducto key={p.id} producto={p} onAgregar={agregar} />
          ))}
        </div>
      </main>
    </>
  )
}
 
export default App
Resultado: el mini catálogo hecho con React
7.8 ¿Cómo funciona?
useState('todas') crea la variable de estado filtro y la función setFiltro para cambiarla. Cada vez que se llama setFiltro, React vuelve a ejecutar App y actualiza la pantalla.
visibles y total no son estado: se calculan en cada dibujo a partir del estado.
setCarrito([...carrito, producto]) crea un arreglo nuevo con el producto agregado. En React no se modifica el estado directamente (carrito.push no funcionaría).
<TarjetaProducto producto={p} onAgregar={agregar} /> le pasa al hijo un dato (el producto) y una función. El hijo llama onAgregar(producto) cuando se pulsa su botón: así los datos bajan por props y los eventos suben por funciones.
<>…</> es un fragmento: permite devolver varios elementos sin agregar un div extra.

Solución

El estilo no se aplica.

En JSX es className.
